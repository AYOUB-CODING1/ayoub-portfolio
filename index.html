Research

F-1: An Educational Reversible Mathematical Cipher

From an inverse function to a tested software model

Independent technical paper, written during my study of reverse engineering. It has not been peer-reviewed or published in a journal.

Abstract

F-1 is a small educational program that turns a mathematical idea, the relationship between a function and its inverse, into a reversible character transformation. It uses the positive divisors of 27,720 as a finite codebook, applies a rational function whose outputs are exact integers, and maps those values to printable characters. The paper explains the mathematics, the software structure, the verification strategy and the limits of the design. F-1 is a learning tool, not secure cryptography.

Key ideas

An inverse that is exact, not approximate
Because every input divides 27,720, the quotient K/x is always an integer. The forward function and its inverse therefore work in whole numbers only, with no floating point, rounding or truncation.
A domain that fits the problem
27,720 = 2³ × 3² × 5 × 7 × 11 has 96 positive divisors. Excluding 1 leaves 95, which matches the 95 printable ASCII characters.
Separating the math from the arrangement
A seed decides how characters are assigned to codebook values. It never changes K, f or its inverse, and the core logic lives in one module that the command line and the graphical interface share.
Testing properties, not examples
The project documents 28 categories of core self-test and a pytest suite of 40 cases. They check the inverse across the whole codebook, round trips for every supported character and for random and long messages, seed reproducibility, and rejection of unsupported or malformed input.
Stating the limits plainly
The mapping is deterministic for a given seed, so it can reveal patterns. A clean inverse is not the same thing as security, and F-1 should never protect real data.

Cayvora

Cayvora is an independent cybersecurity initiative I founded in Morocco. I built and maintain both of its websites myself. Its aim is to raise security awareness, and the clearest expression of that is a set of free tools that work in a person’s own browser, so a password or a photo never has to leave their device.

One of the seven is a glossary of cybersecurity terms in Moroccan Darija, so the vocabulary exists in the language many people use at home.

  • Password strength checker
  • Image metadata stripper
  • Google Dork generator
  • Payload encoder and decoder
  • Darija terms glossary
  • Security headers scanner
  • Social media privacy checklist
